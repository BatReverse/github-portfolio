SPI master on FPGA (VHDL)

Completed
ENSEEIHT computer architecture mini-project · VHDL on a Nexys 4 board with a PmodJSTK joystick

Objectives

  • Implement an SPI master (mode 0) in VHDL, split into reusable components.
  • Build a single-byte full-duplex exchange unit (er_1octet): MSB-first shifting, sclk generation.
  • Build a multi-byte master as a finite-state machine handling ss, slave setup delays and inter-byte waits.
  • Drive a real PmodJSTK joystick from the Nexys 4 FPGA: read the 10-bit X/Y axes and buttons, control its LEDs.

What I learned

  • Writing synthesizable VHDL: clocked processes, clock enables, synchronous/asynchronous resets.
  • Designing FSMs that respect a peripheral's timing constraints (µs-level waits at 1 MHz).
  • Writing testbenches and debugging waveforms with GHDL and GTKWave.

CHIP-8 emulator

Completed
Own CHIP-8 interpreter, written in C with SDL2

Objectives

  • Build a CHIP-8 emulator from scratch in C.
  • Implement the full instruction set: opcode decoding, timers, stack, registers.
  • Use SDL2 for display rendering and keyboard input.
  • Validate correctness against reference test ROMs.

What I learned

  • How a fetch-decode-execute loop works in practice.
  • Low-level bit manipulation for opcode decoding.
  • Using SDL2 for real-time graphics and input handling.
  • Validated against the IBM logo, Corax+ opcode, and BC_test ROMs.

Memory allocator (malloc)

Completed
Own malloc/free/calloc/realloc, written in C

Objectives

  • Reimplement malloc, free, calloc, and realloc in C with no dependency on libc.
  • Request memory from the OS directly via Linux primitives (mmap, sysconf).
  • Reuse and split freed blocks instead of always requesting new pages.
  • Validate the allocator with a unit test suite.

What I learned

  • How mmap-backed heaps and page-aligned allocations work under the hood.
  • Designing a linked-list block allocator (metadata headers, splitting, reuse).
  • Testing memory alignment, calloc zeroing, and realloc grow/shrink semantics.

Unix mini-shell

Completed
Own Unix shell, written in C

Objectives

  • Build a Unix shell from scratch in C, on top of a provided command-line parser.
  • Support multi-command pipelines and I/O redirection (< / >).
  • Support background execution (&) and builtins (cd, exit, rep).
  • Avoid zombie processes and busy-waiting while a foreground command runs.

What I learned

  • Process management with fork/execvp, and chaining pipelines with pipe/dup2.
  • Async-signal-safe reaping of children with a SIGCHLD handler (sigaction, SA_SIGINFO).
  • Blocking/unblocking signals and waiting on a condition with sigsuspend instead of polling.
